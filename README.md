# paperpile-sync (inbox branch)

This branch receives the automatic BibTeX export from the curator's Paperpile label **`DLA-approved`**, written to `bibliography/DLA-approved.bib`.

- It is an **inbox**, not part of the archive. Do not merge it into `main`.
- A work appearing in the `.bib` means the curator has approved it. The intake of each new entry into `main` happens through a change request (see `changes/` and `TODO.md` on `main`).
- A work disappearing from the `.bib` is treated as a withdrawal and logged in `DECISIONS.md` on `main`.

See the `main` branch for the archive itself.
