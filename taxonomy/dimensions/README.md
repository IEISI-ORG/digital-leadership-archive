# Dimensions

Each dimension gets its own file with a definition, in-scope and out-of-scope statements, a reference scheme where one exists, and its values. Template: [dimension.md](../../templates/dimension.md).

Approved by name on 2026-09-26 (D-0005). Definitions are pending (CR-0004).

| Dimension | Covers | Definition |
|---|---|---|
| Leadership level | Who leads: board, C-suite, senior management | pending |
| Leadership function | What leadership activity: e.g. governance, strategy, management, assurance, transformation | pending |
| Industry | Sector of the organisation | pending |
| Organisation type | Listed, private, public sector, not-for-profit | pending |
| Jurisdiction | Legal and regulatory setting | pending |
| Competency domain | Areas of leadership competence | pending |
| Technology domain | Cyber, data, AI, digital transformation, … | pending |
| Evidence type | Empirical study, thesis, practitioner guide, standard, case study, … | pending |

Leadership level and Leadership function are kept separate: who leads is a different question from what leadership activity is being performed.
