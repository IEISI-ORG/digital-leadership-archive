# Standing tiers

The tiers used to classify the standing of lenses. The rules are in [EPISTEMOLOGY.md §2](../../EPISTEMOLOGY.md#2-standing-tiers). Template: [tier.md](../../templates/tier.md).

The list is open: new tiers may be added when the evidence shows patterns the existing ones do not fit. `unclassified` is the default state, not a tier.

| Tier | Summary | Entry |
|---|---|---|
| Empirical | Peer-reviewed empirical support | pending (CR-0005) |
| Practitioner | Documented results in practice; no contradicting empirical work found within a stated scope | pending (CR-0005) |
| Myth | Popular, but refuted on evidence or on method | pending (CR-0005) |
